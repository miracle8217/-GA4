# GA4 GitHub Pages 測試頁

這是一個可直接部署到 GitHub Pages 的 GA4 測試頁面。

## 功能
- GA4 page_view
- 按鈕點擊事件
- 表單送出事件
- 連結點擊事件
- 自訂測試事件

## 使用方式
1. 打開 `index.html`
2. 將 `G-XXXXXXXXXX` 替換成你的 GA4 Measurement ID
3. 上傳到 GitHub repo
4. 到 GitHub 的 `Settings > Pages` 啟用 GitHub Pages
5. 打開產生的網址測試 GA4

## 建議
- 搭配 GA4 DebugView 測試
- 可使用 Chrome 的 GA Debugger 擴充功能
