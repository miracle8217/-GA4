# GA4 數據分析展示網站

這是一個部署在 GitHub Pages 的多頁網站，用來學習 GA4 追蹤、事件設計與網站數據分析。

## 網站目的
- 學習 GA4 基本追蹤
- 練習設計自訂事件
- 觀察使用者行為
- 根據數據優化網站

## 主要功能
- 首頁 / 關於頁 / 聯絡頁
- 按鈕點擊事件
- 頁面瀏覽追蹤
- 外部連結點擊
- 表單送出事件
- 捲動深度追蹤
- 導覽列點擊追蹤

## 追蹤事件
- `page_view`
- `hero_cta_click`
- `home_button_click`
- `about_click`
- `contact_form_submit`
- `outbound_click`
- `scroll_depth`
- `nav_click`

## 學習重點
1. 了解網站如何串接 GA4
2. 了解如何設計事件名稱與參數
3. 了解如何用 Realtime / DebugView 驗證資料
4. 了解如何根據數據改善網站內容與介面

## 部署方式
1. 上傳到 GitHub repository
2. 到 `Settings > Pages`
3. 選 `Deploy from a branch`
4. Branch 選 `main`
5. Folder 選 `/root`
6. 儲存並等待部署完成
