# GA4 多頁 GitHub Pages 測試站

這是一個可部署到 GitHub Pages 的多頁 GA4 測試站。

## 檔案結構
- `index.html`
- `about.html`
- `contact.html`
- `assets/styles.css`

## 測試事件
- `page_view`
- `home_button_click`
- `about_click`
- `contact_form_submit`

## 部署方式
1. 將專案上傳到 GitHub repository
2. 到 `Settings > Pages`
3. 設定 `Deploy from a branch`
4. Branch 選 `main`
5. Folder 選 `/root`
6. 儲存後等待部署完成

## 注意
請將所有檔案中的 `G-XXXXXXXXXX` 替換成你的 GA4 Measurement ID。
