GA4 GitHub Pages 測試頁

這個頁面適合直接部署到 GitHub Pages， 用來測試 GA4 的頁面瀏覽與自訂事件追蹤。

測試目標：page_view、按鈕點擊、表單送出、連結點擊、自訂事件

按鈕事件

點擊以下按鈕，會送出 GA4 自訂事件。

表單事件

輸入文字後送出，會記錄表單事件。


連結事件

點擊連結會送出 link_click 事件：

前往 example.com

自訂測試事件

直接送出一個測試事件，方便確認 GA4 是否正常接收。

部署後檢查清單

  1. 確認 GA4 Measurement ID 已正確替換
  2. 打開 GitHub Pages 網址
  3. 點擊按鈕 / 連結 / 表單
  4. 到 GA4 的 即時報表 或 DebugView 查看事件
建議搭配 Chrome 的 GA Debugger 擴充功能或 GA4 DebugView 一起測試。
